## 🚀 Quick Start

1. **Load Extension**
   - Go to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select the `extension` folder

2. **Try It**
   - Click the extension icon
   - Sign in (uses demo mode - no backend needed)
   - Click the microphone
   - Say: "Schedule a meeting tomorrow at 2pm"
   - Confirm the action
   - Done!
